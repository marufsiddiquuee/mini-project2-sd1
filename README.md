# Galaxy Guide

A single-page educational website about galaxies, built with semantic HTML and Tailwind CSS.

**Live page:** https://marufsiddiquuee.github.io/mini-project2-sd1


## Features

- Sticky navigation bar that collapses into a menu on phones
- Sections on galaxy anatomy, galaxy types, relative sizes, key terms, facts and sources
- Responsive grids that change layout from phone to desktop widths
- Interactive elements: expandable facts (`<details>`) and a three-question quiz
- Accessible markup: semantic elements, labelled bars, keyboard focus styles

## Technologies

- HTML5
- Tailwind CSS, loaded from the Tailwind CDN (no custom CSS or JavaScript)

## Files

- `index.html`: the complete page
- `m51.jpg`: image of the Whirlpool Galaxy (M51). Image credit: NASA, ESA, Hubble

## How to run

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.

An internet connection is needed for the Tailwind styles to load.
